# Abishek Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Personalize before publishing
- Replace `your.email@example.com` with your real email.
- Update LinkedIn and GitHub links with your profiles.
- Add project repository/demo links and any real dates, achievements, certificates, and work experience.
- Review the project descriptions to ensure they match what you want to present publicly.

No build tools or package installation required. Google Fonts are loaded online; system fonts are used if unavailable.
